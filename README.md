# مدرسه گیم — شعبه اول مجازی

مدرسه آنلاین فارسی با پنل جدا برای دانش‌آموز و معلم.

## لینک‌ها
- صفحه اصلی: `/`
- پنل دانش‌آموز: `student.html`
- پنل معلم: `teacher.html`
- اتاق کلاس: `class.html`

## امکانات نسخه ۱
- بدون ثبت‌نام؛ نام در مرورگر ذخیره می‌شود.
- رشته‌های ماینکرفت، کالاف دیوتی، فری فایر، ریاضی، شیمی، بازی‌ها، انگلیسی و کامپیوتر.
- ساخت کلاس با ترم، جلسه ۱ تا ۳۲، تاریخ/ساعت و مدت.
- اتاق کلاس تمام‌صفحه.
- تخته سفید زنده.
- چت گروهی و چت با معلم.
- صدای کلاس با WebRTC.
- معلم می‌تواند برای دانش‌آموز اجازه صحبت باز کند.
- حضور آنلاین و حضور و غیاب پایه.
- کارنامه و نمره ۰ تا ۲۰.

## نکته امنیتی
این نسخه عمداً ورود/ثبت‌نام ندارد. در نتیجه لینک پنل معلم عمومی است و برای استفاده واقعی مدرسه باید احراز هویت و سطح دسترسی اضافه شود.

Backend این نسخه روی Supabase Realtime/Database قرار گرفته است.
